# 🐾 PetAmigos - Campanha de Adoção de Animais

Um site voluntário moderno e responsivo para campanha de adoção de animais de estimação.

## 🎯 Funcionalidades

✅ **Listagem de Animais** - Visualize todos os animais disponíveis para adoção com filtros por tipo  
✅ **Detalhes do Animal** - Histórico completo do animal e informações detalhadas  
✅ **Login/Cadastro** - Sistema de autenticação simples para candidatos  
✅ **Formulário de Adoção** - Candidatos preenchem formulário para expressar interesse  
✅ **Seleção de Local** - Escolha entre 3 locais de retirada do animal  
✅ **Armazenamento Local** - Dados salvos em localStorage (sem necessidade de banco de dados)  
✅ **Design Responsivo** - Funciona perfeitamente em desktop, tablet e mobile  
✅ **Cores Personalizadas** - Azul marinho e amarelo claro conforme solicitado  

## 🚀 Como Usar

### 1. Abrir o Site
Simplesmente abra o arquivo `index.html` no navegador.

### 2. Navegar
- **Home** - Página inicial com informações sobre a instituição
- **Animais** - Lista de animais disponíveis com filtros
- **Adotar** - Formulário para candidatos interessados
- **Login** - Faça login ou cadastre-se

### 3. Fluxo de Adoção
1. Clique em "Ver Detalhes" em um animal
2. Clique em "Quero Adotar"
3. Faça login ou cadastre-se (se não tiver conta)
4. Preencha o formulário de adoção
5. Envie sua candidatura!

## 💾 Dados Armazenados

Os dados são salvos em `localStorage`:
- **Usuários cadastrados** - Emails e senhas
- **Candidaturas** - Formulários de adoção enviados
- **Informações de login** - Sessão do usuário

## 🔧 Personalizações Possíveis

Edite em `script.js`:
- **Adicionar mais animais** - Modifique o array `animaisData`
- **Mudar cores** - Altere as variáveis CSS em `:root`
- **Adicionar funcionalidades** - Estenda o JavaScript
